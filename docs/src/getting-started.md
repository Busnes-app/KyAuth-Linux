# Getting started

## Install and unlock

On Ubuntu Touch, install the arm64 click package from this project's releases. On Nura or a Linux desktop, use the signed Flatpak repository described in the product reference. Set a strong passphrase when creating the vault: Linux has no hardware keystore protecting it from offline guesses.

## Connect KyIdentity

1. On Nura, install a UnifiedPush distributor first. Ubuntu Touch uses Ubuntu Push.
2. In KyIdentity, open Devices and create a pairing code.
3. In KyAuth, open Settings, then Connect your account.
4. On Ubuntu Touch, scan the QR code. On Nura, copy its text using another QR app, choose Enter code manually, then Paste and Pair.

Complete pairing within 90 seconds. Test a sign-in while you still have an alternative way into the account.
